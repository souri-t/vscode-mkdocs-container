# 付録

## 用語集

**JWT**  
JSON Web Token の略。認証情報を表現するトークン形式。

**Bearer Token**  
HTTP ヘッダーで送信する認証トークン。

**Idempotency**  
同一リクエストを複数回実行しても結果が変わらない性質。

## 非機能要件

| 項目 | 内容 |
|------|------|
| タイムアウト | 30秒 |
| 監査ログ保管期間 | 365日 |
| 可用性目標 | 99.9%以上 |
| 最大同時接続数 | 500 |

## 数式サンプル

インライン数式の例として、応答時間の平均値は \( \bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i \) と表せます。

表示数式の例:

\[
SLA = \frac{\text{正常稼働時間}}{\text{総稼働時間}} \times 100
\]

行列式の例:

\[
\det A =
\begin{vmatrix}
a & b \\
c & d
\end{vmatrix}
= ad - bc
\]
